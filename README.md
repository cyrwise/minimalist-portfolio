# Cyrus Wise - Minimalist Portfolio ✨

This is the source code for my current, active portfolio, live at [cyruswise.com](https://cyruswise.com). 

## Overview
After experimenting with highly interactive, gamified web environments, I built this repository to serve as my primary professional hub. It is built to prioritize a clean, aesthetic presentation and a seamless user experience. Utilizing Next.js components, it delivers a fast, responsive, and minimalist design that highlights the content without distractions.

## Features
* **Minimalist UI**: Stripped back and focused entirely on content readability, spacing, and clean aesthetics.
* **Next.js Architecture**: Built with modern Next.js components for optimal routing, performance, and presentation.
* **Fully Responsive**: Scales beautifully and maintains its minimalist integrity across all device sizes.

## Local Setup
To run this project locally:

1. Clone the repository:
   ```bash
   git clone [https://github.com/cyrwise/minimalist-portfolio.git](https://github.com/cyrwise/minimalist-portfolio.git)
   ```

2. Navigate into the directory:
   ```bash
   cd minimalist-portfolio
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
